# Associate — Complete Frontend Demo Build Prompt for Lovable

> **Purpose:** Build a complete, demo-ready interactive frontend for Associate — the AI workspace built for Indian lawyers. This is not a dashboard. It is a workspace. The default platform a lawyer opens every morning. Design language is editorial, serif-heavy, warm paper aesthetic. Reference: *Financial Times Weekend*, not Salesforce.

---

### Typography
- **Display / Headings:** `Fraunces` (serif, variable optical size 9–144, weights 300–700) from Google Fonts
- **UI / Labels / Body text:** `Inter Tight` (weights 400, 500, 600) from Google Fonts
- **Indian language text:** `Noto Sans Devanagari` (weights 400, 500) — used for Odia/Hindi rendered text

### Aesthetic Rules
- Background: always `var(--paper)`, never white or grey
- No metric tiles, no KPI cards, no charts, no widget dashboards
- Information lives in **prose**, not in boxes
- Typography is the interface — headings large, body Fraunces serif, labels Inter Tight small-caps
- Borders: always `var(--rule)` or `var(--rule-soft)`, never dark outlines
- Hover states: subtle background shift to `var(--paper-deep)`, never color changes
- Active/selected states: `var(--ink)` background, `var(--paper)` text (ink-on-paper inversion)
- Animations: 0.15–0.3s ease-out only. Fade + 4px translateY. No bounces, no spring physics.

## ANIMATIONS AND TRANSITIONS

- **View switches** (Home ↔ Matter): opacity 0→1 + translateY 4→0px, 0.3s ease-out
- **Drawer slides**: translateX(100%) → translateX(0), 0.25s ease-out, simultaneously backdrop fade-in
- **Modal open**: scale(0.96)→scale(1) + opacity 0→1, 0.2s ease-out
- **New matter dot appears**: scale(0)→scale(1) + sage green glow pulse, 0.4s
- **Agent narrative types in**: progressive text reveal (character by character), ~20ms/char, then resolve
- **Suggestion cards**: staggered fade-up, 80ms apart
- **Toast**: slides up from bottom-center, holds 2.4s, fades out
- **Language toggle**: cross-fade text content, 0.25s
- **Tracked changes reveal**: deleted text shows in oxblood strikethrough with margin note animation
- **Fresh chronology item**: sage-green highlight that fades to sage-soft over 2s (see @keyframes highlightIn)
- **Chat responses**: typing indicator (3 dots, 800ms) then message fades in

All transitions: ease-out, never spring or bounce. Duration range: 0.12s (hover) to 0.4s (major transitions).

## IMPLEMENTATION NOTES FOR LOVABLE

1. **Single HTML file** — all CSS, JS, fonts in one self-contained file. No build step, no bundler.
2. **State management** — simple JS object: `{ activeMatter, activeView, openDrawer, openModal, chatOpen, editorOpen }`. No Redux needed.
3. **All data** — hardcoded as JS constants at the top. No API calls in demo.
4. **Font loading** — Google Fonts CDN link in `<head>`. Fraunces + Inter Tight + Noto Sans Devanagari.
5. **No external UI libraries** — pure CSS, no Bootstrap, no Tailwind, no component libraries.
6. **Odia/Hindi text** — hardcoded Unicode strings. Use `font-family: 'Noto Sans Devanagari', serif` on those elements.
7. **DocEditor** — a styled `contenteditable` div. Not a real editor. Rich content is hardcoded HTML rendered inside it.
8. **All overlays** — `position: absolute` or `position: fixed`, z-index layered correctly.
9. **Keyboard shortcuts** — Escape closes topmost open overlay. ⌘K opens chat.
10. **Mobile** — not required for demo. Optimize for 1280px+ screen width.
11. **Demo sequence** — build so that a presenter can click through the full flow in under 3 minutes: Home → Varma matter → Files drawer → Playbook drawer → Open document → See indemnity track change → Open chat → Ask about indemnity → See response with SC citation → Close → Create new NIT matter → See it created → Open → See trilingual MoU → Toggle Odia → Toggle Hindi → Open compliance → See compliance calendar → Share modal.
